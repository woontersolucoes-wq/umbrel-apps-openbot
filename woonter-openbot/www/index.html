Comandos no terminal do umbrelOS

Vincular este servidor à sua conta (uma vez, troque NOME pelo nome que vai aparecer no app): docker exec -it woonter-openbot_server_1 openbot login --name NOME Ver o estado e a memória: docker exec woonter-openbot_server_1 openbot status Ler o log: docker logs --tail 100 woonter-openbot_server_1 Conectar o app do celular: docker exec -it woonter-openbot_server_1 openbot mobile-connect
